# Lovable PDF Converter

Free Online PDF Tools — Simple, Fast, and Accessible.

Lovable PDF Converter is a web application designed to make working with PDF documents easier. It brings useful PDF utilities together in one place, with a focus on simplicity, accessibility, and an intuitive user experience.

## ✨ Features

* **Compress PDF** — Reduce PDF file sizes.
* **Merge PDF** — Combine multiple PDF documents.
* **Split PDF** — Extract selected pages from a PDF.
* **Organize PDF** — Reorder and manage document pages.
* **Convert PDF** — Convert supported document formats.
* **Protect PDF** — Add password protection to supported PDF documents.
* **Unlock PDF** — Remove supported PDF restrictions when authorized.
* **Additional PDF Tools** — Explore other available document utilities.

*Feature availability depends on the current implementation. Some tools may require additional backend configuration.*

## 🚀 Run Locally

### Prerequisites

* Node.js
* npm

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/hanumanteprajwal7-ctrl/lovable-pdf-converter.git
   ```

2. Open the project directory:

   ```bash
   cd lovable-pdf-converter
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local address displayed in your terminal.

### Production Build

To create a production build, run:

```bash
npm run build
```

The generated frontend files are placed in the `dist` directory.

## 🌐 Deployment

This project is being prepared for deployment using Vercel.

The frontend and backend may require separate deployment configuration, depending on the server-side functionality used by individual tools.

## 🔐 Security

* Never commit API keys, passwords, or private environment variables.
* Keep local environment files out of version control.
* Only upload documents you are authorized to process.
* Use password protection and document unlocking responsibly.

## 🎯 Project Goal

The goal of Lovable PDF Converter is to make everyday PDF operations more convenient by bringing useful document tools together in one accessible application.
